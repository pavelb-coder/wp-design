# Тесты плагина WP Olympiad Design

Тесты гоняются в [WordPress Playground](https://wordpress.github.io/wordpress-playground/)
(CLI `@wp-playground/cli`), без внешней БД и без установки PHP.

Версия 1.3.0 проверена на PHP 7.4.33 и WordPress 7.1.3, на чистой базе, в порядке A → B → D → E → F → J → C.
Ранее (1.2.0) — на PHP 7.4.33 (blueprint с `preferredVersions.php = 7.4`) и на версии по умолчанию PHP 8.5.10. Версия подтверждается скриптом `PHP_VERSION`, а не заголовком `X-Powered-By`. Фазы A, B, C на обеих версиях проходят на чистой базе.

## Запуск

1. Скопируйте `wp-olympiad-design` в папку, которую монтирует Playground (`/wordpress/wp-content/plugins/`).
2. Поднимите сервер WordPress:
   ```bash
   npx @wp-playground/cli@3.1.59 server --auto-mount=<папка_с_WordPress> \
     --blueprint=tests/playground/blueprint.json --blueprint-may-read-adjacent-files --port=9400
   ```
   `blueprint.json` задаёт `preferredVersions.php` (например, `7.4`) и активирует плагин.
3. Скопируйте `wpd-test-a.php`, `wpd-test-c.php`, `wpd-set.php` в корень WordPress и выполните:
   ```bash
   curl -sL http://127.0.0.1:9400/wpd-test-a.php > resA.txt   # фаза A, выводит строку IDS
   WPD_BASE=http://127.0.0.1:9400 bash phaseB.sh               # фаза B, читает resA.txt из текущей папки
   curl -sL http://127.0.0.1:9400/wpd-test-c.php               # фаза C, последней: удаляет данные плагина
   ```

Важно: Playground хранит базу SQLite в `<папка_с_WordPress>/wp-content/database/`.
Чтобы начать с чистой базы, остановите сервер и удалите файлы `.ht.*` в этой папке.
Фаза C удаляет настройки и мета-поля плагина, поэтому запускайте её последней. `wpd-measure.php` сам создаёт опцию перед замером, потому что фильтр `option_*` не срабатывает для отсутствующей опции.

   Фазы 1.3.0 (после фазы B, до фазы C; `wpd-test-d.php` тоже скопируйте в корень WordPress):
   ```bash
   curl -sL http://127.0.0.1:9400/wpd-test-d.php > resD.txt   # фаза D, выводит строку IDS
   WPD_BASE=http://127.0.0.1:9400 bash phaseE.sh               # фаза E, читает resD.txt
   WPD_BASE=http://127.0.0.1:9400 python3 wpd-browser-test.py ./shots   # фаза F, нужен pip-пакет playwright и Chromium
   ```
   Фаза F сама закрывает приветственный гид и окно выбора паттерна редактора и раскрывает область Meta Boxes.
   Скриншоты сайта после фазы F лежат в `screenshots/`.

4. Проверка JavaScript (нужен Node.js). Берётся HTML страницы с включёнными функциями (`f_features.html`, его сохраняет фаза B) и `wpd.js`:
   ```bash
   mkdir -p /tmp/jsdom && cd /tmp/jsdom && npm install jsdom@24
   cp /home/user/wp-design/tests/playground/wpd-js-test.cjs .
   node wpd-js-test.cjs /tmp/pg/f_features.html /home/user/wp-design/wp-olympiad-design/assets/js/wpd.js
   ```

Фаза B опирается на состояние базы, которое оставляет фаза A (тестовые страницы, FAQ `Q?`, блоки), поэтому всегда начинайте с чистой базы.

`wpd-set.php` — служебный хелпер: меняет опцию плагина по GET-параметру `json`. Только для песочницы, в продакшен не копируйте. WordPress экранирует `$_GET` (`wp_magic_quotes`), поэтому в хелпере нужен `stripslashes()`. Без него JSON не разбирается.
