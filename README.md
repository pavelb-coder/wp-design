# wp-design

## Плагины

- [`wp-olympiad-design`](wp-olympiad-design/README.md) — оформление страниц в стиле сайта олимпиады: главный блок, статистика, документы и FAQ-аккордеон. Общие настройки — отдельный пункт меню «Олимпиада» с вкладками; для каждой страницы — панель «Блоки олимпиады» (порядок, видимость, своё содержимое); блоки редактора «Олимпиада: …» с правкой текста прямо на странице. С 1.5.0 — компоненты главной страницы в духе шаблона «Нодес»: слайдер, кнопки-ссылки, карточки, объявление, новости, контакты и палитры; работают с любой темой. С 1.6.0 — таймер до начала и до окончания в одном блоке и кнопка со ссылкой на время этапа; с 1.6.1 — даты таймера по московскому времени (часовой пояс выбирается); с 1.7.0 — название организации со ссылкой в контактах; с 1.8.0 — больше параметров главного блока (вторая кнопка, изображение слева или фоном с затемнением, свой фон, высота, выравнивание, размер заголовка) и раздел «Типографика и вид» (шрифт и цвет заголовков, размер текста, ширина, отступы, форма и вид кнопок, тени); с 1.9.0 — иконки кнопок, таймер в главном блоке, шрифты Google и свой CSS; с 2.0.0 — регистрация участников: форма с конструктором полей, личный кабинет, заявки со статусами и выгрузкой в CSV, письма, сроки и лимит мест; с 2.1.0 — участник задаёт пароль при регистрации и может сменить его в личном кабинете.
