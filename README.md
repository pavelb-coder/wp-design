# wp-design

## Плагины

- [`wp-olympiad-design`](wp-olympiad-design/README.md) — оформление страниц в стиле сайта олимпиады: главный блок, статистика, документы и FAQ-аккордеон. Общие настройки — отдельный пункт меню «Олимпиада» с вкладками; для каждой страницы — панель «Блоки олимпиады» (порядок, видимость, своё содержимое); блоки редактора «Олимпиада: …» с правкой текста прямо на странице. С 1.5.0 — компоненты главной страницы в духе шаблона «Нодес»: слайдер, кнопки-ссылки, карточки, объявление, новости, контакты и палитры; работают с любой темой.
