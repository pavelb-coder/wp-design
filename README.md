# wp-design

## Плагины

- [`wp-olympiad-design`](wp-olympiad-design/README.md) — оформление страниц в стиле сайта олимпиады: главный блок, статистика, документы и FAQ-аккордеон. Общие настройки — отдельный пункт меню «Олимпиада» с вкладками; для каждой страницы — панель «Блоки олимпиады» (порядок, видимость, своё содержимое); блоки редактора «Олимпиада: …» с правкой текста прямо на странице. С 1.5.0 — компоненты главной страницы в духе шаблона «Нодес»: слайдер, кнопки-ссылки, карточки, объявление, новости, контакты и палитры; работают с любой темой. С 1.6.0 — таймер до начала и до окончания в одном блоке и кнопка со ссылкой на время этапа; с 1.6.1 — даты таймера по московскому времени (часовой пояс выбирается); с 1.7.0 — название организации со ссылкой в контактах; с 1.8.0 — больше параметров главного блока (вторая кнопка, изображение слева или фоном с затемнением, свой фон, высота, выравнивание, размер заголовка) и раздел «Типографика и вид» (шрифт и цвет заголовков, размер текста, ширина, отступы, форма и вид кнопок, тени); с 1.9.0 — иконки кнопок, таймер в главном блоке, шрифты Google и свой CSS. Регистрация участников и личный кабинет (2.0.0–2.1.0) убраны в 2.2.0 вместе с их данными. С 2.3.0 — стиль оформления «Мягкий градиент» по макету Кванториума (включается в настройках): мягкие цветные пятна, крупный заголовок, круглая иллюстрация Лондона и Красноярска, стеклянные карточки, FAQ в две колонки, логотип в контактах. С 2.9.0 — свои шрифты (файлы WOFF2/WOFF/TTF/OTF и таблицы стилей Adobe Fonts, Fontshare, Bunny, ParaType и др.) для текста, заголовков, главного блока, кнопок и цифр — в общих настройках, для страницы и у каждого блока; логотип в главном блоке, свой логотип в контактах и блок «Логотипы партнёров»; SVG — только для администраторов, с очисткой. В 2.10.0 импорт документов из сетевой папки (2.8.0) убран вместе с импортированными данными. С 2.11.0 — прозрачность каждого фона (0–100 %) и размеры заголовков, основного и второстепенного текста у всех блоков — в настройках, для страницы и в блоках редактора.
