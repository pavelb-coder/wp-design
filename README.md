# wp-design

## Плагины

- [`wp-olympiad-design`](wp-olympiad-design/README.md) — оформление страниц в стиле сайта олимпиады: главный блок, статистика, документы и FAQ-аккордеон. Общие настройки — «Настройки → Дизайн олимпиады»; для каждой страницы — панель «Блоки олимпиады» (порядок, видимость, своё содержимое); блоки редактора «Олимпиада: …» с правкой текста прямо на странице.
